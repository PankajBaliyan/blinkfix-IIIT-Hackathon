Where we are now
----------------
Working:
  - Demo service with 3 deliberate bugs (TypeError, ZeroDivisionError, TimeoutError)
  - Crash detection, webhook, log fetching and console report
  - Incidents, agent results, patches and logs saved in SQLite
  - API to list and read incidents
  - Frontend with live polling, light/dark mode and a sidebar
Still simulated:
  - The 5 agents return canned text (Cerebras is never called)
  - Candidate patches come from a fixed library for the 3 demo bugs
  - Test results for patches are canned numbers
  - GitHub pull request and Slack message are faked in demo mode
