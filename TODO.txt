NOTES ON A1/A2 (what exists now)
--------------------------------
- Model: gpt-oss-120b (set in server/.env). qwen-3.8-27b is also available to the key.
- Per incident: 1 shared "triage" call answering all 5 agent roles, + 1 patch call.
- Each agent checks its section of the answer; if it is missing or invalid the agent
  falls back to its built-in demo analysis and says so in its activity log.
- A client-side limiter keeps calls under CEREBRAS_MAX_RPM. If the next free slot is
  further than CEREBRAS_MAX_WAIT_S away, the call is skipped and the built-in
  analysis / patch library is used.
- Patches are checked by applying them to the real file and parsing the result.
  Tests are NOT run ("not run" in the UI) until B2/B3 are built.
